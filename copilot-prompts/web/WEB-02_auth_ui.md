# WEB-02 — Auth UI (Login / Register)

## Objectif
Permettre à l’utilisateur de se connecter à l’application.

## Tâches
1) Pages:
    - /login
    - /register
2) Formulaires PrimeNG:
    - email
    - password
3) Appels API via services OpenAPI générés
4) Gestion des erreurs (401, validation)

## Contraintes
- Utiliser uniquement les services OpenAPI générés
- UX simple et claire

## DoD
- Login OK
- Redirection vers AppShell après login
